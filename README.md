**Social Media Management Platform**

A robust, centralized web application built to manage multiple social media channels, streamline publishing, and handle audience engagement from a single dashboard.



**Overview**

The Social Media Management Portal is designed to simplify social media operations for businesses and creators. By integrating directly with major platform APIs (including Facebook, Whatsapp, Instagram, YouTube, and Messenger), the application enables users to schedule and publish posts, monitor comments, and manage direct communications efficiently.



**Key Features**


Multi-Platform Integration: Connect and manage accounts across Meta ecosystems (WhatsApp, Facebook Pages, Instagram Business/Creator accounts, Messenger) and YouTube.

Manage Direct Messaging across Meta ecosystems (WhatsApp, Instagram Business/Creator accounts, Messenger) 
Content Publishing: Create, review, Delete rich media posts, captions, and updates directly to connected platforms.

Engagement & Comment Management: Track and reply to incoming comments and audience interactions from a unified interface.

Human Agent Messaging Support: Handle messaging workflows and leverage specific API tags (such as the human_agent messaging tag) for compliant customer support interactions.




**Tech Stack**

Backend: PHP (Yii 2 Framework)

Frontend:  PHP (Yii 2 Framework), Bootstrap 5, HTML5, CSS3, JavaScript

APIs & Integrations: Meta Graph API, Instagram Graph API, YouTube Data API, Facebook Messenger API
